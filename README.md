## Project Overview

An interactive data analytics dashboard analyzing automobile sales trends and the relationship between automobile sales and recession periods.

The project uses **Python, Pandas, Plotly, and Dash** to perform data analysis and create interactive visualizations.

## 📊 Live Interactive Dashboard

**[Open the Live Dashboard](https://automobile-sales-dashboard-ytbk.onrender.com/)**

Explore automobile sales trends, yearly statistics, recession-period analysis, vehicle-type comparisons, advertising expenditure, and the relationship between unemployment and automobile sales.

## 📓 Jupyter Notebook

**[View the Data Analysis Notebook](https://github.com/FelixAkanno/automobile-sales-dashboard/blob/main/automobile_sales_visualization.ipynb)**

The notebook contains the data analysis, visualization development, and exploratory work behind the dashboard.

## 📈 Key Analysis

The dashboard provides interactive visualizations for:

* Yearly automobile sales trends
* Monthly automobile sales
* Automobile sales by vehicle type
* Advertising expenditure by vehicle type
* Automobile sales during recession periods
* Vehicle-type performance during recessions
* Advertising expenditure during recessions
* Relationship between unemployment rates and automobile sales
